V7.31 — แสดงชื่อบริษัทจริงบนการ์ด LINE ผู้อนุมัติ

อัปไฟล์ approver-line.js ไปทับที่:
deal-line-bot/src/approver-line.js

แก้แล้ว:
- การ์ด "คุณได้รับสิทธิ์ผู้อนุมัติแล้ว" แสดงชื่อบริษัทจริงจาก _settings.company_name
- ไม่ใช้คำกว้าง ๆ "บริษัทนี้" ถ้ามีชื่อบริษัทในระบบ
- การ์ดแจ้งใบเบิกรออนุมัติจะแสดงชื่อบริษัทจริงเช่นกัน
- สิทธิ์เก่าจะถูกเติม companyName กลับเข้า KV ตอนกด "ส่ง LINE ใหม่" หรือมีแจ้งเตือนครั้งถัดไป
- altText ของ LINE ระบุชื่อบริษัทด้วย
